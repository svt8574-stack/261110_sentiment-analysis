# 02 — UI 디자인 구현 지침

## 레퍼런스와 해석
첨부한 `docs/ui-reference.png`는 공차 홈페이지의 데스크톱 화면이다. 관찰 가능한 특징은 **화면을 채우는 차/밀크 이미지**, **넓은 여백**, **상단의 얇은 오버레이 내비게이션**, **중앙에 놓인 흰색 로고**, **큰 흰색 헤드라인**, **우측 플로팅 원형 버튼**, **따뜻한 크림·브라운·레드 계열**이다.

브랜드 로고, 메뉴, 원본 문구, 실제 사진을 그대로 사용하지 않는다. 서비스 고유 브랜드 `ONDO`를 적용하고, 따뜻한 음료/종이 질감/빛의 그림자처럼 차분한 감성만 재해석한다. 라이선스 확인된 이미지가 없다면 **CSS 그라디언트와 원형 도형**으로 히어로를 구현한다. 제공된 스크린샷은 결과물에 배경 이미지로 직접 사용하지 않는다.

## 디자인 토큰 (CSS 변수)
```css
:root {
  --color-cream: #F7F2EC;
  --color-sand: #E8D9C9;
  --color-ink: #352A28;
  --color-muted: #746660;
  --color-accent: #A33D45;
  --color-positive: #3F7660;
  --color-negative: #A34C58;
  --color-neutral: #7C706B;
  --color-white: #FFFFFF;
  --radius-card: 24px;
  --radius-pill: 999px;
  --shadow-soft: 0 16px 50px rgba(53,42,40,.10);
  --content-width: 1120px;
}
```
- 기본 폰트: 시스템 한글 산세리프(`Pretendard`가 로컬에 없으면 `Apple SD Gothic Neo`, `Malgun Gothic`, sans-serif). 웹폰트 외부 로딩은 필수가 아니다.
- 히어로 제목: 데스크톱 `clamp(2.25rem, 4.4vw, 4.25rem)`, 모바일 `clamp(2rem, 8vw, 3rem)`.
- 본문 16~18px, 줄간격 1.5 이상, 최대 본문 폭 65ch.
- 애니메이션은 200~400ms 페이드/이동 정도만 사용한다.

## 반응형 동작
- 1024px 이상: 헤더 좌·중·우 3영역, 히어로 넓은 레이아웃, 카드 최대 680px.
- 768~1023px: 좌우 패딩 32px, 타이포 축소.
- 767px 이하: 헤더는 로고와 `감정 분석` 링크만 남긴다. 패딩 20px, 카드 100%, 버튼 너비 100%.
- 최소 검증 너비 360px. 콘텐츠가 화면 밖으로 넘치지 않아야 한다.
- 원본의 우측 플로팅 버튼은 MVP 기능과 무관하므로 구현하지 않는다. 불필요한 기능을 흉내 내지 않는다.

## 상태 디자인
- 초기: 입력 카드만 표시, 결과 카드 숨김.
- 로딩: 버튼 텍스트 `분석 중...`, 스피너(장식), `aria-live` 상태 문구.
- 성공: 감정 라벨과 색상 강조, 신뢰도 %, 이유; 색상만으로 감정을 구분하지 않는다.
- 오류: 입력 영역 가까이에 읽기 쉬운 오류 메시지, 기존 성공 결과는 숨김.

## 접근성·완료 기준
- 실제 `<label for>`와 `textarea id`를 연결한다.
- 키보드 Tab/Enter(버튼)/Space로 조작할 수 있다. `textarea`의 Enter는 줄바꿈이다.
- 버튼과 텍스트는 충분한 대비, 포커스 테두리를 가진다.
- 로딩/오류/결과 변경을 `role="status"` 또는 `aria-live="polite"`로 전달한다.
- `prefers-reduced-motion: reduce`에서 모션을 제거한다.
- 360/768/1440px에서 레이아웃·가독성·가로 스크롤 여부를 검사한다.
